# Workflows n8n à exporter

Les exports JSON sont à déposer ici après nettoyage.

Ne jamais versionner :
- credentials ;
- clés API ;
- tokens ;
- données d'exécution ;
- payloads contenant des données personnelles ;
- données provenant des volumes n8n.

Convention recommandée :
- 01-agent-tools.json
- 02-whatsapp-router.json
- 03-calendar-actions.json
- 04-mail-actions.json
